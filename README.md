1. Phân tích lỗi & Lập bảng Test Cases (README.md)Phân tích nguyên nhân kỹ thuật:Trong JavaScript, các câu lệnh điều kiện if (giá_trị) sẽ tự động ép kiểu giá_trị về boolean (Truthy/Falsy). Các giá trị như 0, false, "" (chuỗi rỗng), null, undefined, và NaN đều bị coi là Falsy.Khi kiểm tra if (updatedData.isActive) và truyền vào { isActive: false }, điều kiện này tương đương với if (false), khiến luồng xử lý bị bỏ qua. Tương tự với if (updatedData.powerWatts) khi nhận giá trị 0, điều kiện trở thành if (0) (Falsy) và lệnh cập nhật không được thực thi. Điều này vi phạm nghiệp vụ vì false và 0 là những dữ liệu cấu hình hoàn toàn hợp lệ của thiết bị.Bảng 02 Test Cases đối chứng:Trường hợp kiểm thửDữ liệu đầu vào (updatedData)Kết quả sai thực tế (Code cũ)Kết quả đúng mong đợi (Nghiệp vụ)(1) Tắt điều hòa phòng khách đang bật{ isActive: false }Bị bỏ qua lệnh cập nhật, điều hòa vẫn giữ trạng thái isActive: truetargetDevice.isActive được cập nhật thành false(2) Hạ công suất đèn ngủ đang sáng về 0W{ powerWatts: 0 }Bị bỏ qua lệnh cập nhật, công suất giữ nguyên mức cũ (ví dụ 15W)targetDevice.powerWatts được cập nhật thành 0
